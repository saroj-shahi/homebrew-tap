# saroj-shahi/tap

Homebrew casks for [VibeCheck](https://github.com/saroj-shahi/vibecheck), a menu bar app that tells you if your
Mac is vibing or cooked.

```bash
brew trust --cask saroj-shahi/tap/vibecheck   # Homebrew asks you to trust taps from outside its own repos
brew install --cask saroj-shahi/tap/vibecheck
brew upgrade --cask vibecheck
brew uninstall --cask vibecheck        # add --zap to remove settings too
```
